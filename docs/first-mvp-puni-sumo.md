# First MVP Seed: Puni Sumo

Puni Sumo is not the first final product.
It is the first test seed for the forge.
The real goal is not only to complete Puni Sumo.
The real goal is to prove this loop:
Human idea → GameRecipe → Kit selection → Assembler → generated game → validation → human playtest.

## MVP definition

- Title: 森のぷに相撲
- Play time: within 60 seconds
- Input: mobile drag / keyboard fallback
- Camera: soft isometric
- Stage: small forest arena
- Rule: ring out
- Mood: miniature diorama, soft, playful
