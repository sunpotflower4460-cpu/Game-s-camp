# Concept

**Game’s Camp / AI Game Forge** is a workshop OS where AI assembles games from structured recipes, reusable kits, and templates.

## Core idea

- The concept is close to an AI-native version of Nintendo Switch's "はじめてゲームプログラミング" mindset.
- Instead of humans connecting nodes manually, AI connects Kits according to GameRecipe constraints.
- GitHub is not only a code storage place; it is the AI's operational workshop for planning, generation, validation, and repair.
- Before giving AI freedom, we design a world where AI does not get lost: clear contracts, order, and validation gates.
