# Puni Sumo Custom Layer
This directory is reserved for human or AI-authored custom adjustments for the Puni Sumo sample game.
## Purpose
`custom/` is the protected layer.
Generated files may be overwritten by future renderer or assembler scripts.  
Custom files must never be overwritten by generation.
## What belongs here
- game-specific notes
- custom visual hints
- custom rule extensions
- small hand-authored adjustments that should survive regeneration
## What does not belong here
- generated output
- template-rendered files
- Phaser runtime implementation
- files that should be overwritten automatically
## Current phase
Phase 5.5 only creates the custom layer skeleton.
This custom layer is not connected to runtime yet.
